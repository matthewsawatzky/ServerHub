# ServerHub v1.0.0

First public release. ServerHub is a self-contained personal server
dashboard: one Go binary, SSH-only, no runtime dependencies.

## Added

- Dashboard with live CPU / memory / disk cards for every server plus the
  local machine (5s polling, sparkline history)
- Server detail pages: system info, capability probes (tmux, docker, rsync,
  sftp, sudo, iperf3), disks and load
- Full PTY web terminals (xterm.js over WebSocket, vendored, works offline)
  for remote servers and the host itself
- Docker container management (start / stop / restart), image lists, and live
  container logs — remote and local
- Quick actions: runbook buttons with inline output and a Stop button;
  detached tmux jobs with observe / attach / stop / dismiss
- Schedules: recurring or one-off quick actions and commands across servers
  and tags, month/hour calendar with run-now, overlap control, timeouts, and
  history that reflects real command exit codes
- On-demand network probes (ping both directions, DNS, HTTP, traceroute) and
  5-second iperf3 bandwidth tests
- First-run setup wizard with optional password protection (bcrypt, 30-day
  sessions, brute-force lockout)
- TOFU-pinned SSH host keys; host/origin guards against DNS-rebinding and
  cross-site requests
- Server search (Cmd/Ctrl+L), favorites, persistent server URLs, restart /
  shutdown confirmations, accent colour + shade theming, in-app audit log
- Static single binary for 8 platforms (linux/darwin/windows, amd64/arm64),
  packaged as binaries plus macOS DMGs with `checksums.txt`
- Auto-refreshing schedules/calendar with server-vs-local clock awareness
  (times shown in your timezone, offsets surfaced)
- Release tooling: `build.sh` (8 platforms) and `release.sh` (clean-tree
  checks, tests, checksums, tagged GitHub releases with Added/Changed/Fixed
  notes)
