Configuration file

ServerHub stores its configuration in config.yaml in the OS config directory. Theme and animation preferences are saved automatically.

servers:
  - id: my-server
    name: "my-server"
    host: "192.168.1.50"
    port: 22
    user: "youruser"
    key: "~/.ssh/id_ed25519"
    tags: ["homelab"]
    notes: "Optional notes"
    quick_actions:
      - label: "Restart nginx"
        command: "sudo systemctl restart nginx"

Prerequisites

SSH key: Generate with ssh-keygen -t ed25519 and copy to each server with ssh-copy-id user@host.

Docker access: Add your user to the docker group: sudo usermod -aG docker $USER
Or grant NOPASSWD sudo for docker only in /etc/sudoers:
youruser ALL=(ALL) NOPASSWD: /usr/bin/docker

Quick actions

Quick actions are shell commands defined per-server in config. They run as the configured SSH user and their output is streamed back to the UI.

Password

No password is set on this instance. Anyone who can reach the dashboard can use its APIs and terminals. Setting one takes a few seconds.

Your password is active. Changing it signs out every device — you stay signed in here.

Access

Set bind: "127.0.0.1" in config to restrict access to localhost, or use your Tailscale IP to expose it to your tailnet only. Never bind to 0.0.0.0 on an untrusted network.
